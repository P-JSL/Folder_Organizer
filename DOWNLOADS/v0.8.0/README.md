# Folder Organizer 0.8.0 보관본

최신 배포를 0.7.0으로 되돌리기 전에 원래 0.8.0 정식 파일을 그대로 보관했습니다. 코드 검사·프로그램 실행·재빌드를 반복하지 않았으며, 내려받은 파일이 기존 배포와 같은지만 SHA-256으로 확인했습니다.

| 파일 | 용도 |
| --- | --- |
| [FolderOrganizer-Windows-x64.zip](FolderOrganizer-Windows-x64.zip) | Python판 Windows x64 |
| [FolderOrganizer-Rust-Windows-x64.zip](FolderOrganizer-Rust-Windows-x64.zip) | Rust판 Windows x64 |
| [SHA256SUMS.txt](SHA256SUMS.txt) | 원본 ZIP 체크섬 |
| [VALIDATION_RESULTS.zip](VALIDATION_RESULTS.zip) | 원래 빌드·검증 자료와 실제 Windows 화면 |
| [ARCHIVE_INFO.json](ARCHIVE_INFO.json) | 출처·바이트 수·보관 파일 해시 |

이 버전의 실행 파일은 미서명 상태입니다. 사용은 권리자 P-JSL 본인과 명시적으로 서면 허락받은 사람에게만 허용하며 ZIP의 `LICENSE` 및 `licenses/FolderOrganizer/` 조건을 확인하세요.
