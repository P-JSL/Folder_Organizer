# v0.9.0 원본 배포 파일 보관

최신 릴리즈를 v0.7.0으로 되돌리기 전에 원래 배포 파일을 그대로 보관했습니다. 이 폴더는 현재 권장 버전이나 자동 업데이트 대상이라는 뜻이 아닙니다.

- [Python Windows ZIP](FolderOrganizer-Windows-x64.zip)
- [Rust Windows ZIP](FolderOrganizer-Rust-Windows-x64.zip)
- [SHA256SUMS.txt](SHA256SUMS.txt)
- [기존 배포 확인 기록](VALIDATION_RESULTS.zip)
- [파일 크기·전송 해시·원래 빌드 소스](ARCHIVE_INFO.json)

실행 파일을 재빌드하거나 압축을 다시 생성하지 않았습니다. 앱 검사와 화면 캡처도 다시 실행하지 않았습니다. 원래 서명 모드는 unsigned입니다.

사용은 권리자 P-JSL과 명시적으로 서면 허락받은 사람에게만 허용됩니다. ZIP 안의 LICENSE와 licenses/FolderOrganizer 문서 및 제3자 라이선스를 따릅니다.
