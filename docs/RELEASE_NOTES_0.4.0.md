Windows용 로컬 폴더 정리 앱 v0.4.0입니다. 기능을 찾기 쉬운 상단 메뉴, 화면 모드, 다양한 분류 규칙과 실행 로그, 겹치는 문서 내용 병합을 추가했습니다.

- 파일·검사·정리·기록·보기·도구·도움말 헤더 드롭다운으로 기능을 모으고 메인 화면의 버튼을 줄였습니다.
- 다크 모드가 기본이며 보기 메뉴에서 라이트 모드로 전환할 수 있습니다. 선택은 이 컴퓨터에 저장됩니다.
- 완전 중복 결과의 ‘첫 번째 파일만 남기고 나머지 삭제’를 알아보기 쉽게 표시합니다. 미리보기와 확인 뒤 복원 가능한 안전 보관으로 이동하며, 보호 파일과 첫 파일은 남습니다.
- 규칙 편집에 한글·영문 매핑 기호와 날짜 기준을 추가했습니다. `{규칙}/{종류}/{연도}/{월}`, `{수정일:%Y/%m/%d}`, `{생성일:%Y-%m}` 같은 폴더 경로를 만들 수 있습니다.
- 수정일·생성일, 일별·월별·분기별·원래 폴더·규칙 이름 프리셋과 경로 예시를 제공합니다. 생성일을 제공하지 않는 파일은 필요한 규칙에서 건너뛰고 알립니다.
- 기록 메뉴의 실행 로그에서 실제 정리·복원·병합·복구 작업과 파일별 결과를 검색·필터링·내보낼 수 있습니다. 앱 전체의 활동·진단 로그 및 실제 복원용 작업 기록과 구분합니다.
- 체크한 UTF-8 텍스트·Markdown의 완전히 같은 문단, 같은 열 구조 CSV·TSV의 완전히 같은 행을 한 번씩 남긴 새 병합본을 만들 수 있습니다. 서로 다른 내용과 처음 나타난 순서를 보존합니다.
- 병합은 원본을 남기는 방식이 기본입니다. 원하면 병합본 검증 뒤 원본을 안전 보관할 수 있으며 작업 기록에서 원본을 복원해도 병합본은 유지됩니다.
- 기존 파일 덮어쓰기 방지, 실행 전·실행 중 변경 검증, 보호 사본과 기록 기반 복원, 검증 후 앱 종료 시 적용하는 Windows 자동 업데이트를 유지합니다.

`FolderOrganizer-Windows-x64.zip` 전체를 압축 해제하고 `FolderOrganizer.exe`를 실행하세요. Python 설치가 필요 없습니다. `_internal`과 업데이트 도우미를 함께 보관하세요. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.

내용 병합은 2~20개, 파일당 8 MiB·전체 32 MiB의 `.txt`·`.md`·`.csv`·`.tsv`를 지원합니다. 문장의 의미나 충돌을 판단하거나 이미지·Office·실행 파일을 병합하지 않습니다. 유사도 점수는 완전 중복의 증명이 아닙니다. 안전 보관은 영구 삭제가 아니며 디스크 공간을 즉시 확보하지 않습니다. 손상 파일 복구는 읽을 수 있는 데이터만 새 파일로 보존하는 방식입니다.

실제 화면과 사용 순서는 저장소의 [화면별 사용 안내](https://github.com/P-JSL/Folder_Organizer/blob/v0.4.0/docs/GUI_GUIDE.md)를 참고하세요. 실행 파일은 코드 서명되지 않았습니다. 중요한 자료는 별도 백업을 유지하세요.
