# 자동 분류와 보존 규칙 안내

자동 분류는 사용자가 정한 규칙으로 **분류안을 만드는 기능**입니다. 미리보기를 확인하고 실행해야 파일이 변경됩니다. 백그라운드에서 폴더를 감시하거나 확인 없이 파일을 삭제하는 기능은 아닙니다.

![자동 분류 규칙 편집 화면](classification.png)

## 처음 사용하는 순서

1. 개인 자료의 작은 복사 폴더를 선택하고 분석합니다.
2. **정리** 메뉴에서 규칙 분류를 열고 **종류별**, **수정 연월별·일별·분기별**, **생성 연월별**, **원래 폴더별**, **규칙 이름별** 추천 규칙을 고릅니다. 처음에는 기본 동작인 **복사**를 사용하세요.
3. 분류할 파일의 조건과 대상 폴더를 정합니다. 구체적인 규칙을 위로, 넓은 규칙을 아래로 배치합니다. 여러 규칙에 맞으면 **첫 번째 일치 규칙**을 사용합니다.
4. 보호 폴더와 결과 저장 위치를 확인합니다. 맞는 규칙이 없거나 보호 대상인 파일은 원래 위치에 남습니다.
5. 미리보기에서 원본·대상 경로, 적용 규칙, 건너뛴 이유를 확인한 뒤 실행합니다.
6. 완료 후 결과를 확인하고 필요하면 **작업 기록 · 복원**에서 되돌립니다.

## 규칙을 정하는 가이드

| 목적 | 조건 예 | 대상 폴더 예 | 확인할 점 |
| --- | --- | --- | --- |
| 사진을 월별 보관 | 확장자 `jpg`, `jpeg`, `png`, 수정일 기준 | `사진/{연도}/{월}` | 날짜는 파일 수정일입니다. 사진 촬영일 EXIF를 읽어 분류하는 기능은 아닙니다. |
| 생성일로 일별 보관 | 생성일 기준 | `생성일/{날짜}` 또는 `{생성일:%Y/%m/%d}` | 실제 생성일을 제공하지 않는 파일은 건너뛰고 알립니다. 수정일로 대체하지 않습니다. |
| 청구서를 따로 보관 | 이름 `*청구서*`, 확장자 `pdf`, 규칙 이름 `회사 청구서` | `문서/{규칙}/{연도}` | 문서의 실제 내용을 이해하는 분류는 아닙니다. 파일 이름과 지정 조건을 사용합니다. |
| 분기별 자료 모으기 | 수정일 기준 | `{연도}/{분기}분기/{종류}` | `{분기}`는 1~4입니다. |
| 특정 프로젝트 유지 | 상대 폴더 `프로젝트A/*` | `프로젝트A/{원래폴더}` | 폴더 내부 파일을 분류하며 원래 상대 폴더 구조를 보존할 수 있습니다. 빈 폴더 자체를 이동하지 않습니다. |
| 나머지 자료 정리 | 제한 없는 마지막 규칙 | `{종류}/{확장자}` | 이 규칙을 먼저 놓으면 아래의 구체적인 규칙이 적용되지 않습니다. |

사용 가능한 조건은 확장자 목록, 파일 이름 패턴, 상대 폴더 패턴, 최소·최대 크기와 날짜 범위입니다. 날짜 기준은 **수정일(기본)** 또는 **생성일**이며 시작일과 종료일을 모두 포함합니다. 패턴의 `*`는 여러 글자, `?`는 한 글자입니다. 조건을 여러 개 넣으면 모두 만족해야 합니다. 확장자 비교는 대소문자를 구분하지 않습니다.

## `{규칙}` 매핑으로 대상 폴더 만들기

저장할 하위 폴더에 매핑 기호를 입력하거나 편집기의 기호 선택 기능을 사용합니다. 한글·영문 기호를 섞어 쓸 수 있습니다.

| 한글 기호 | 영문 기호 | 값 |
| --- | --- | --- |
| `{종류}` | `{type}` | 사진·문서·동영상 등 파일 종류 |
| `{확장자}` | `{ext}` | 점 없는 확장자 |
| `{원래폴더}` | `{source_folder}` | 원래 상대 폴더 구조, 루트 파일은 `루트` |
| `{규칙}` | `{rule}` | 일치한 규칙의 이름 |
| `{이름}` | `{name}` 또는 `{stem}` | 확장자를 제외한 파일 이름 |
| `{연도}`·`{월}`·`{일}` | `{year}`·`{month}`·`{day}` | 선택한 날짜 기준의 연도·두 자리 월·일 |
| `{날짜}`·`{요일}` | `{date}`·`{weekday}` | `2026-10-28` 형식의 날짜·한글 요일 |
| `{분기}`·`{주차}` | `{quarter}`·`{week}` | 1~4분기·ISO 주차(01~53) |
| `{시}`·`{분}`·`{초}` | `{hour}`·`{minute}`·`{second}` | 선택한 날짜 기준의 두 자리 시·분·초 |
| `{수정일:%Y/%m/%d}` | `{modified:%Y/%m/%d}` | 기준 선택과 관계없이 수정일로 연/월/일 폴더 생성 |
| `{생성일:%Y-%m}` | `{created:%Y-%m}` | 기준 선택과 관계없이 실제 생성 연월 |

`{modified_year}`·`{created_year}` 또는 `{수정연도}`·`{생성연도}`처럼 날짜의 출처를 직접 지정할 수도 있습니다. ISO 주차는 연말·연초에 날짜 연도와 다를 수 있으므로 ISO 주차 연도가 필요하면 `{modified:%G}/W{modified:%V}`를 사용하세요.

날짜 형식에 허용되는 기호는 `%Y`(연도), `%m`(월), `%d`(일), `%H`(시), `%M`(분), `%S`(초), `%j`(연중 일수), `%u`(ISO 요일), `%V`(ISO 주차), `%G`(ISO 주차 연도), `%%`(문자 %)입니다. 경로의 `/`는 하위 폴더를 만듭니다. 생성일이 필요한 조건·기호를 사용했는데 실제 생성일이 없으면 해당 파일을 건너뛰며 경고를 표시합니다.

이 매핑은 **대상 폴더**를 정합니다. 실제 파일 이름은 그대로 붙으며 이름 충돌은 새 이름으로 처리합니다. 편집기의 가상 경로 예시는 실제 파일을 바꾸지 않습니다. 미리보기에서 각 원본과 실제 대상 경로를 다시 확인하세요. 절대 경로, `..`, Windows 예약 장치 이름, 복원 기록 폴더를 템플릿으로 사용할 수 없으며 코드·속성 접근을 실행하지 않습니다.

## 중복 자동 분류는 별도입니다

**완전 중복 검사**를 마친 뒤 원본 보존 기준을 선택합니다. 최근·오래된 수정일, 경로 또는 선호 폴더 기준과 보호 폴더를 검토하세요. 자동 분류는 검증된 중복 사본의 **안전 보관안**을 만들며 유사한 파일에는 적용하지 않습니다. 보호 폴더의 파일과 각 그룹의 보존 원본은 남깁니다.

미리보기 후에도 보존 원본과 사본을 다시 확인합니다. 원본이 사라지거나 바뀌었으면 해당 중복 정리를 진행하지 않습니다. 이름·텍스트·이미지 유사도 100%는 완전 중복 증명이 아니므로 자동 보관의 근거가 될 수 없습니다.

## 첫 번째 파일 제외 삭제

완전 중복 검사 결과에서 **첫 번째 파일만 남기고 나머지 삭제**를 사용할 수 있습니다. '첫 번째'는 그룹 화면에 나열된 첫 파일이며 최신 수정일이나 원본의 품질을 뜻하지 않습니다. 미리보기에서 남길 파일과 사본을 확인하세요. 보호 폴더의 파일도 자동 삭제 대상에서 제외합니다.

이 버튼의 삭제는 원래 위치에서 파일을 제거해 **안전 보관으로 이동**하는 방식입니다. 영구 삭제나 Windows 휴지통 비우기를 수행하지 않습니다. 기존 보존 규칙을 사용한 자동 분류와 별개로 첫 번째 보존 기준을 고정하며, 같은 실행 재검증과 작업 기록 복원을 적용합니다. 공간을 즉시 확보하지는 않습니다.

## 두 단계 보호와 복원

- **실행 전 보호:** 전체 분류안과 적용 규칙 확인, 파일 전체 지문 검증, 보호 폴더 제외, 대상 충돌·안전 경로·여유 공간 확인을 수행합니다.
- **실행 중 보호:** 원본·대상과 중복 보존 원본을 재검증합니다. 검증된 복사본을 만든 뒤에만 원래 경로의 파일을 보호 보관으로 옮깁니다. 기존 파일을 덮어쓰지 않으며 각 결과를 서명된 작업 기록에 저장합니다.
- **실행 후 복원:** 원래 폴더에서 작업 기록을 열어 복원을 요청합니다. 정리 후 수정되었거나 원래 경로에 다른 파일이 생기면 충돌을 표시하고 해당 파일을 보존합니다.

격리·이동도 보호 사본을 남기므로 저장 공간을 즉시 확보하지 않습니다. 여유 공간 검사는 실행 전의 상태이며 다른 프로그램의 동시 쓰기까지 예약하지는 못합니다. 오류가 나면 결과와 로그를 확인하세요. `.folder-organizer` 기록과 보호 사본을 지우면 복원할 수 없습니다.

실행 파일 이름이 비슷하다는 이유로 설치된 프로그램을 대체하거나 제거하지 않습니다. 시스템·설치 폴더와 앱 묶음의 내부 파일은 일반 자료처럼 자동 이동하지 않습니다.
