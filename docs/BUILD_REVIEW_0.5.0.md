# v0.5.0 Windows 변경 표와 사용 확인

v0.5.0은 Windows 정식 릴리스로 제공합니다. [Windows ZIP과 체크섬](https://github.com/P-JSL/Folder_Organizer/releases/tag/v0.5.0)을 다운로드하거나, 자동 업데이트가 켜진 Windows 배포 앱에서 새 버전을 확인하세요. 이 문서는 시험용 빌드부터 사용한 변경 표와 확인 항목을 정식 버전 기준으로 정리한 안내입니다.

| 추가·변경 기능 | 사용하는 곳 | 동작 |
|---|---|---|
| 첫 파일 제외 즉시 정리 | 중복 결과의 전용 버튼 | 현재 검증 결과를 재사용해 첫 파일과 보호 파일을 남기고 나머지를 `delete_files`로 이동합니다. 추가 전체 검사·확인 화면 없이 실행합니다. |
| 삭제 보관 폴더 통합 | 선택 폴더의 `delete_files` | 새 삭제·복원에서 `quarantine`·`retained`를 만들지 않습니다. 보관한 파일은 일반 목록에서 제외합니다. |
| NAS·Windows 휴지통 확인 | 삭제 실행 시 자동 | NAS `#recycle` 존재나 Windows 휴지통 조회 성공만으로 파일별 복원을 보장하지 않습니다. 이 빌드는 미검증 OS 삭제 대신 `delete_files` 보관을 사용합니다. |
| 용량·정리 요약 | 검사 메뉴 | 폴더·종류·큰 파일·수정 시기·빈 파일을 조회하고 목록에서 체크할 수 있습니다. |
| 빠른 필터·최근 폴더 | 파일 목록·파일 메뉴 | 100 MiB 이상·0 B·수정 후 1년을 표시하고 최근 폴더를 새로 분석합니다. |
| 빠른 유사 후보 | 검사 설정 | 큰 목록에서 제한된 후보를 전체 파일에 걸쳐 찾습니다. 일부 유사 쌍은 놓칠 수 있다고 표시합니다. |
| 압축 복원 정보 | 작업 기록에서 자동 | 인증된 압축 메타데이터와 기존 기록을 사용하며 압축이 부적합하면 기존 방식으로 전환합니다. |
| 복원 데이터 용량 최적화 | 작업 기록의 해당 버튼 | 같은 1 MiB 조각을 공유하고 압축·원시 저장 중 작은 쪽을 선택합니다. 보관 사본을 줄이기 전에 데이터와 기록을 검증합니다. |

처음 확인할 때는 복사한 작은 폴더를 사용하세요. 같은 내용의 파일 여러 개를 검사한 뒤 전용 버튼을 누르면 각 그룹의 첫 파일은 남고 나머지는 `delete_files`에 나타나며 앱 목록에서는 사라집니다. **기록 → 작업 기록 · 복원**으로 되돌린 뒤 원래 내용이 같은지 확인할 수 있습니다. 같은 이름의 다른 파일이 생긴 경로는 덮어쓰지 않습니다.

NAS 휴지통 자체의 실제 정책은 NAS 관리자 설정과 권한에 좌우됩니다. `#recycle`은 발견 여부만 표시하며, 이 버전이 NAS 서버의 고유 복원 기능을 검증했다고 간주하지 않습니다. 복원에는 보관된 실제 데이터가 필요하며 메타데이터만으로 잃어버린 원문을 만들 수는 없습니다.

패키지 ZIP을 폴더 전체로 압축 해제하고 `FolderOrganizer.exe`를 실행하세요. `_internal`, `FolderOrganizerUpdater.exe`, `version.json`을 함께 유지해야 합니다. 공개 릴리스 절차는 [RELEASE_PROCESS.md](RELEASE_PROCESS.md), 실제 측정 범위는 [PERFORMANCE.md](PERFORMANCE.md)에 있습니다.
