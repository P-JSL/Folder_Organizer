Windows용 로컬 폴더 정리 앱 **v0.5.0 정식 릴리스**입니다. 기존 중복 검사 결과를 재사용하는 즉시 정리와 `delete_files` 보관, 용량 요약과 빠른 필터, 큰 목록의 조회·분석 개선, 실제 복원 데이터의 중복 제거·압축을 추가했습니다.

- 기존 중복 검사 결과에서 첫 파일과 보호 파일만 남기고 나머지를 추가 전체 검사·확인 없이 `delete_files`로 이동합니다. 삭제 후 목록도 재탐색 없이 갱신하며 새 삭제·복원에서는 `quarantine`과 `retained`를 만들지 않습니다.
- Windows·NAS 휴지통 상태와 접근 가능한 NAS의 `#recycle` 존재는 읽기 전용으로 확인합니다. 폴더 존재나 휴지통 조회 성공만으로 파일별 복원을 보장할 수 없어, **이 버전의 새 삭제는 모두 `delete_files`로 이동**합니다. 미검증 OS 삭제를 실행하거나 서버 휴지통 폴더에 직접 넣지 않습니다. 삭제 보관 폴더들은 일반 분석에서 제외합니다.
- 기록에서 명시적으로 선택한 복원 보관본을 1 MiB 조각 중복 제거·무손실 압축으로 최적화하고, 검증·기록 저장 후에만 기존 사본을 줄입니다.
- **검사 → 용량·정리 요약**에서 종류·상위 폴더별 용량, 큰 파일과 빈 파일을 확인할 수 있습니다. 요약을 여는 것으로 파일이 변경되지는 않습니다.
- 목록의 대용량·빈 파일·오래된 파일 필터와 최근 폴더 메뉴를 추가했습니다. 최근 폴더는 현재 상태를 새로 분석하며, 화면 필터는 전체 검사 범위를 바꾸지 않습니다.
- 파일 목록은 항목을 순차 탐색하고 목록 생성 중 불필요한 정렬과 과도한 진행 이벤트를 줄였습니다. 화면 정렬과 실제 파일 내용을 읽는 비용은 별도입니다.
- 큰 목록의 유사 비교는 자동으로 제한된 후보 인덱스를 사용해 앞쪽 파일에만 비교 한도를 쓰는 문제를 줄입니다. 전체 파일을 방문해 후보를 찾지만 일부 유사 쌍을 놓칠 수 있으며, 전체 쌍 검사와 결과 범위를 구분해 표시합니다.
- 완전 중복 판정은 크기·전체 SHA-256·실제 바이트 검증을 유지합니다. 빠른 후보나 이름 유사도를 삭제 근거로 쓰지 않습니다.
- 조건에 맞는 완료 작업은 경로·해시·복원 정보를 인증된 압축 메타데이터로 추가 저장합니다. 압축 이득이 작거나 시간이 오래 걸리면 기존 기록을 사용합니다. 압축 기록을 사용할 수 없으면 유효한 기존 기록으로 전환하고 이유를 알립니다.
- 메타데이터는 복원 설명서이며 실제 파일 내용의 대체물이 아닙니다. `delete_files`의 원본 또는 검증된 압축 보관 데이터와 인증된 작업 기록이 함께 있어야 복원할 수 있습니다. 이전 버전의 보관 사본·기록은 호환을 유지하며, 파일 손상 복구는 읽을 수 있는 내용을 새 파일로 보존하는 기존 방식을 유지합니다.
- 용량 요약·검사 범위·검색 방식·압축 복원에 대한 사용자 안내와 재현 가능한 성능 측정 도구를 보강했습니다.

`FolderOrganizer-Windows-x64.zip` 전체를 압축 해제하고 `FolderOrganizer.exe`를 실행하세요. Python 설치가 필요 없습니다. `_internal`과 업데이트 도우미를 함께 보관하세요. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.

자동 업데이트가 켜진 Windows 배포 앱은 새 정식 버전을 확인·검증해 준비하고, 파일 작업을 마친 뒤 앱 종료 후 적용합니다. 안전 보관은 복원 가능한 이동이며 디스크 공간을 즉시 확보하지 않습니다. **`delete_files`와 `.folder-organizer`의 기록·인증 정보·보관 데이터를 함께 유지**해야 복원할 수 있습니다.

실제 화면과 사용 순서는 저장소의 [화면별 사용 안내](https://github.com/P-JSL/Folder_Organizer/blob/main/docs/GUI_GUIDE.md), 처리 비용과 측정 범위는 [성능 안내](https://github.com/P-JSL/Folder_Organizer/blob/main/docs/PERFORMANCE.md)를 참고하세요.
