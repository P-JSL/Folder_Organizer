Windows용 로컬 폴더 정리 앱 v0.3.0입니다. 작업 기록 화면 안정화, 진행도·로그, 규칙 자동 분류와 분석 속도 개선을 반영했습니다.

- 작업 기록의 중첩 데이터·큰 파일 식별자를 Qt에 직접 전달하지 않는 평면 모델과 비중첩 복원 흐름
- 현재 단계의 처리 수·백분율, 경과 시간과 가능한 경우 남은 시간 추정
- 로컬 UTF-8 순환 로그, 검색·수준 필터·로그 내보내기와 비정상 종료 진단
- 종류·날짜·폴더 기본 규칙과 이름·확장자·폴더·크기·수정일 조건의 사용자 규칙
- 복사 기본값, 미리보기·추가 확인, 보호 폴더·여유 공간·원본 재검증과 기록 기반 복원
- 완전 중복 자동 안전 보관 및 별도의 '첫 번째 파일만 남기고 나머지 삭제' 기능
- 큰 파일의 표본 사전 제외와 변경 검증을 갖춘 제한된 메모리 특징 캐시; 최종 중복은 전체 해시와 바이트 비교 유지

- 파일별 용량·수정일·생성일 조회, 검색·정렬·CSV 내보내기
- 완전 중복과 유사 후보 분리, 이름·텍스트·이미지별 점수·기준값·판정 한계 표시
- 두 파일의 전체 해시·정보·텍스트 차이·이미지를 나란히 검토
- 검증된 중복에만 적용하는 보존 규칙, 선호·보호 폴더와 변경된 파일 재검증
- 저장되는 검사 프리셋, 제외 경로 패턴과 파일 크기 범위
- 근거·검사 범위·경고를 포함한 JSON/HTML 분석 보고서
- 미리보기와 확인 후 날짜·확장자 정리, 선택 폴더 복사·이동
- 별도 '선택 항목을 중복으로 간주' 버튼, 격리 보관 및 작업 되돌리기
- ZIP·Office·이미지·PDF 검사와 가능한 데이터의 새 파일 복구
- 새 정식 릴리스 자동 확인·다운로드, 검증 후 종료 시 업데이트 적용

`FolderOrganizer-Windows-x64.zip` 전체를 압축 해제하고 `FolderOrganizer.exe`를 실행하세요. Python 설치가 필요 없습니다. `_internal` 폴더를 함께 보관하세요. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.

중요한 원본은 백업하고 작은 복사 폴더에서 먼저 검증하세요. 유사 파일은 자동 중복이 아니며, 격리는 디스크 공간을 확보하지 않습니다. 손실된 데이터·암호·영구 삭제된 디스크 파일은 복원할 수 없습니다. 실행 파일은 코드 서명되지 않았습니다. 자세한 지원 범위와 제한은 README를 확인하세요.
