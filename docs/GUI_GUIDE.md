# 화면에서 기능 이해하기

아래 이미지는 개인 자료 대신 임시 예시 파일로 **실제 앱을 실행해 캡처한 화면**입니다. 설치된 사용자 설정과 원본 자료를 사용하지 않았습니다.

## 처음에는 폴더만 선택하세요

![처음 실행한 화면](welcome.png)

폴더를 선택하면 파일별 용량과 날짜를 살펴봅니다. 이 단계에서는 파일이 바뀌지 않습니다. 상단은 현재 상태에 맞춰 다음 작업을 안내합니다. **기능 안내 · F1**은 파일을 바꾸지 않는 설명 창입니다.

## 목적에 맞는 기능을 고르세요

![파일 목록 화면](screenshot.png)

| 하고 싶은 일 | 사용할 기능 | 실행 결과 |
| --- | --- | --- |
| 같은 내용을 여러 번 저장했는지 확인 | 중복 검사 · 같은 내용 | 내용이 완전히 같은 파일을 그룹으로 보여줍니다. 검사만으로 변경하지 않습니다. |
| 비슷한 사진이나 문서 버전 비교 | 유사 비교 · 비슷한 내용 | 직접 확인할 후보를 보여줍니다. 높은 점수는 완전 중복의 뜻이 아닙니다. |
| 종류·날짜·원하는 조건으로 폴더 나누기 | 자동 분류 · 폴더 나누기 | 규칙으로 분류안을 만들며 복사가 기본입니다. 분석한 전체 파일 중 조건에 맞는 항목을 사용합니다. |
| 직접 고른 파일을 복사·이동·보관 | 체크 → 아래 정리 방식 → 미리보기 | 파일 목록에서 체크한 항목만 수동 작업 대상으로 사용합니다. |
| 이전 작업 되돌리기 | 작업 기록 · 복원 | 변경되지 않고 충돌하지 않는 파일을 확인해 작업을 되돌립니다. |
| 진행 상황이나 오류 확인 | 활동 로그 | 작업 과정을 설명합니다. 로그 화면 자체는 파일을 복원하지 않습니다. |

행을 클릭해 강조하는 것과 **체크 상자를 선택하는 것**은 다릅니다. 체크한 파일은 검색으로 숨겨도 선택이 남습니다. 화면의 ‘숨겨진 파일 포함’ 안내와 미리보기의 전체 대상 목록을 확인하세요.

## 중복 결과에서는 남길 파일을 정하세요

![중복 결과 화면](comparison.png)

‘남길 파일 정하기’는 보존 규칙에 따라 사본을 체크합니다. 이때도 파일은 바뀌지 않습니다. ‘첫 번째 파일만 남기고 나머지 삭제’는 표시된 첫 파일과 보호 파일을 남기는 **별도의 안전 보관 미리보기**입니다. 첫 번째가 최신 파일이라는 의미는 아닙니다. 안전 보관은 원래 위치에서 옮기는 방식이며 작업 기록에서 복원할 수 있지만 디스크 공간을 즉시 확보하지 않습니다.

비교 탭에서는 결과를 넓게 보여줍니다. 파일 목록의 검색·종류·검사 범위는 ‘전체 파일’ 탭에서 다시 확인할 수 있습니다. 전체 검사 범위와 화면 표시 필터는 다릅니다. 자동 분류와 중복 사본 정리는 체크·화면 필터가 아닌 검사 범위에서 계획을 만듭니다.

## 규칙은 예시를 보며 편집하세요

![규칙 작성과 경로 예시](classification.png)

추천 규칙을 선택하고 이름·확장자·저장할 하위 폴더를 편집합니다. 아래 가상 예시가 적용 조건과 예상 경로를 설명합니다. 예시는 파일을 실제로 읽거나 분류한 결과가 아닙니다. 폴더·용량·날짜 조건은 필요할 때 펼칠 수 있으며 접어도 저장된 조건은 유지됩니다. 날짜의 연도·월은 파일 수정일입니다.

실제 대상은 다음 미리보기에서 확인합니다. 복사는 원본이 남고, 이동·안전 보관은 원래 위치가 바뀝니다. 자동 분류 실행에는 경로 확인과 체크 확인 절차가 있으며 기존 안전 검증과 복원 기록을 유지합니다.

## 기능별 예시를 검색하세요

![검색 가능한 기능 안내](help.png)

14개 주제에서 ‘언제 쓰나요 → 어떻게 사용하나요 → 실행하면 어떻게 되나요’를 읽을 수 있습니다. ‘사진’, ‘첫 번째’, ‘복원’처럼 궁금한 말로 검색하세요. 자세한 판정 기준은 필요한 경우에 펼칩니다.

작업 기록과 로그의 실제 화면: [작업 기록·복원](history.png), [활동 로그](logs.png). 로그는 한글 설명이 기본이며 지원용 기술 정보는 선택해서 펼칠 수 있습니다.

개발 환경에서 같은 예시 화면을 재생성하려면 `QT_QPA_PLATFORM=offscreen python scripts/capture_ui.py`를 사용합니다. 프로젝트 의존성이 설치되어 있어야 하며 `docs`의 일곱 PNG 파일을 갱신합니다.
