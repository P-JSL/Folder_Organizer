# v0.9.0 메인 화면 사용 안내

Python판과 Rust판 모두 여러 폴더를 **메인 화면에서 함께 분석**하는 흐름으로 시작합니다. 폴더 간에 같은 내용의 파일이 있는지 살펴본 다음, 실제 정리가 필요하면 한 폴더를 골라 정리 화면으로 이동합니다.

## 화면에서 찾을 수 있는 것

| 위치 | 용도 |
| --- | --- |
| 상단 메뉴·작업 버튼 | 폴더 추가, 분석 시작·취소, 결과 저장과 기존 정리·기록·도움말 기능 |
| 왼쪽 폴더 목록 | 분석할 폴더 등록, 포함 여부 선택, 목록에서 제거, 하위 폴더·숨김 파일 등 분석 범위 확인 |
| 가운데 결과 | 전체 파일과 완전 중복 그룹 전환, 이름·경로·용량·날짜 확인 |
| 오른쪽 파일 정보 | 선택한 결과의 전체 경로·파일 크기·날짜와 중복 근거 확인 |
| 진행·상태 표시 | 분석 진행, 폴더별 실패, 취소·부분 결과 구분 |

오른쪽 정보는 **분석할 때 얻은 정보**입니다. 목록의 행을 누를 때마다 파일을 다시 열거나, 파일 내용을 자동 미리보기하지 않습니다. 분석 후 외부 프로그램이 파일을 바꿨다면 다시 분석한 결과로 현재 상태를 확인하세요.

## 여러 폴더를 함께 확인하기

1. **폴더 추가**로 비교할 위치를 등록합니다. 다른 드라이브나 접근 가능한 NAS 공유 폴더도 등록할 수 있습니다.
2. 왼쪽 목록에서 이번에 분석할 폴더를 체크합니다. 목록에서 제거하는 동작은 등록 경로만 제거하며 실제 폴더를 삭제하지 않습니다.
3. 하위 폴더·숨김 파일 등 범위를 확인한 뒤 분석을 시작합니다. 이번 분석은 체크한 범위의 파일 목록과 완전 중복을 함께 확인합니다.
4. 전체 파일에서 크기·날짜를 살펴보고, 완전 중복 결과에서 같은 내용의 파일이 어느 폴더에 있는지 확인합니다.
5. 필요하면 선택한 입력 폴더 **밖의 새 파일**에 JSON 결과를 저장합니다. 기존 보고서를 덮어쓰지 않습니다.

최대 64개 폴더를 등록할 수 있습니다. 폴더별 접근 권한과 네트워크 상태에 따라 일부 위치를 읽지 못할 수 있습니다. 폴더 목록을 등록했다는 것만으로 NAS 연결이나 읽기 권한을 보장하지는 않습니다.

## 통합 결과와 실제 정리의 차이

**통합 분석은 폴더가 한 개여도 읽기 전용입니다.** 파일을 조회하고 폴더 간 완전 중복을 확인하는 단계이며, 그룹의 첫 항목이 가장 좋은 원본이라는 뜻은 아닙니다. 같은 이름만으로 완전 중복이라고 판단하지 않습니다.

파일을 옮기거나 정리하려면 왼쪽에서 실제 폴더 하나를 선택하고 **이 폴더에서 정리**로 이동하세요. 선택 폴더의 기존 정리 흐름에서 새로 분석한 뒤 중복·유사 비교, 규칙 분류, 복사·이동, 기록·복원을 사용할 수 있습니다. 통합 결과를 곧바로 삭제 권한이 있는 단일 폴더 결과로 바꾸지 않습니다.

선택 폴더의 검증된 중복 결과에서 **첫 번째 파일만 남기고 나머지 삭제**를 실행하면, 현재 결과를 사용해 첫 파일과 보호 대상을 남기고 사본을 해당 폴더의 `delete_files`로 이동합니다. 이 버튼은 추가 전체 재검사·확인 창 없이 실행됩니다. 실행 중 파일의 식별 정보·변경 여부 확인은 유지하며, 변경을 발견하면 해당 작업을 중단합니다. 통합 분석에서는 이 버튼으로 여러 폴더의 파일을 삭제할 수 없습니다.

`delete_files`로 이동한 바이트는 여전히 디스크를 사용합니다. 복원하려면 해당 폴더의 `delete_files`와 `.folder-organizer`의 기록·키·복원 데이터를 함께 유지하세요. 기존 정리 기능의 자세한 사용법은 [화면별 기능 안내](GUI_GUIDE.md)에 있습니다.

## 취소·실패가 표시되면

- 분석 중 취소하면 중단한 시점까지의 결과만 남을 수 있습니다. **취소·부분 결과**는 모든 폴더의 검사가 끝났다는 뜻이 아닙니다.
- 파일 목록 조회가 끝났더라도 내용 검사를 취소하면 완전 중복 분석은 미완료일 수 있습니다. 목록 완료와 전체 완료를 따로 확인하세요.
- 접근하지 못한 폴더·읽지 못한 파일은 상태와 경고로 확인합니다. 결과가 없다는 이유만으로 중복이 없다고 단정하지 마세요.
- 폴더나 분석 범위를 바꾼 뒤에는 분석을 다시 시작해야 새 범위의 결과를 얻습니다. 결과 화면의 현재 범위와 상태를 함께 확인하세요.

분석 엔진의 중첩 폴더·하드링크 처리, 동시 작업 제한과 보고서 필드는 [통합 분석 기술 안내](MULTIROOT_ANALYSIS.md)를 참고하세요. 여러 폴더를 병렬로 읽어도 같은 볼륨·NAS 서버는 보수적으로 순서대로 조회하며, 작업 수를 늘린다고 항상 빨라지는 것은 아닙니다.
