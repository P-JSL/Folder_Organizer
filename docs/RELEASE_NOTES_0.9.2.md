# Folder Organizer v0.9.2 · Python / Rust

클라우드 개발 환경 설정과 최신 안내 문서를 보존하는 패치 릴리즈입니다.
파일 분석·정리·복원 기능과 의존성은 v0.9.1과 동일합니다.

- `.codex/environment`에 Python·Rust 도구, Linux 데스크톱, 클라우드 내부 Windows VM의 설치·시작 스크립트를 추가했습니다.
- 기존 VM 디스크 보존, 비밀번호 비출력, 관리형 프록시·인증서 유지, 정상 종료 후 환경 게시 절차를 문서화했습니다.
- Windows 탐색기·원격 화면 준비 오류와 평가판 활성화 HTTP 503, 현재 채팅의 공유 뷰어 도구 부재를 명시했습니다. 이 릴리즈는 해당 문제가 해결됐다는 뜻이 아닙니다.
- 최신 개발·운영 개선 제안 보고서를 소스에 포함했습니다. 제안된 앱 기능의 구현이나 성능 향상을 새로 주장하지 않습니다.

Python판과 Rust판은 별도 Windows x64 ZIP으로 제공합니다. 새 버전 표식을 반영하려고
정식 빌드하며, 이미 통과한 앱 검사·CLI·GUI 실행·화면 캡처는 반복하지 않습니다.
두 ZIP의 체크섬은 `SHA256SUMS.txt`에서 확인하세요.

개인 VM 상태·비밀번호·설치 XML·디스크·로그는 릴리즈 소스와 첨부 파일에 포함하지 않습니다.
앱 릴리즈 게시와 Codex 클라우드 환경 게시는 별개입니다.
