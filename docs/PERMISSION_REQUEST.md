## 요청 방법

권리자가 직접 안내하거나 확인한 연락 수단으로 요청하세요. 공개 문의를 남기는 경우에는 비공개 연락 수단을 요청하는 정도의 최소 정보만 쓰고, 실제 파일·주민등록번호·비밀번호·인증 키·토큰을 올리지 마세요. 공개 GitHub 이슈 작성이 이용허락이나 수락을 뜻하지는 않습니다.

요청에는 아래 항목만 필요한 범위에서 포함하면 됩니다.

```text
요청자 식별자: GitHub 사용자명 등
답변 가능한 연락 수단:
이용 목적: 개인 비영리 / 조직 내부 업무 / 상업적 이용 등
실제 이용자: 개인 또는 별도로 합의할 조직·사용자 범위
이용할 판과 버전: Python / Rust, 버전 범위
기간·기기 범위:
필요한 추가 권한: 수정 / 재배포 / 서비스 제공 등, 없으면 없음
요청한 조건·제한 사항:
```

권리자의 명시적인 답변 전에는 허락받은 것으로 간주하지 않습니다. 다른 사용자가 전달한 사본이나 허락 증빙은 요청자에 대한 새 허락이 아닙니다.

## 권리자가 발행할 수 있는 허락 기록 예시

다음은 **빈 양식**이며 이 문서 자체는 누구에게도 이용허락을 부여하지 않습니다. 권리자가 실제 대상과 범위를 적고 직접 발행하거나 확인해야 효력이 있는 허락 증빙으로 사용할 수 있습니다.

```text
Folder Organizer 개별 이용허락

허락 식별번호 또는 발행일:
권리자: P-JSL
허락받는 사람·조직 및 실제 사용자 범위:
허용하는 판·버전:
허용 목적:
허용 기간·기기 범위:
상업적 이용: 허용 / 불허, 구체적인 범위
수정·재배포·서비스 제공: 허용 / 불허, 구체적인 범위
업데이트·지원 범위:
대가·환불 등 별도 합의: 해당 시에만
적용할 LICENSE·이용약관 문서 버전:
특별 조건과 일반 조건 중 달리 합의한 사항:
권리자 확인: 서명 또는 권리자가 직접 보낸 확인 기록
```

허락 증빙에는 프로그램 이용 범위만 담고 사용자 파일의 소유권·공개권을 넘기는 조건을 임의로 추가하지 마세요. 허락 증빙을 다른 사람의 이용권처럼 공유·양도·재허락하는 행위는 별도로 허용하지 않는 한 금지됩니다. 법령상 제출, 법원·법률대리인·감사 등 정당한 권리 증빙과 비공개 확인을 위한 제공은 제외합니다. 권리자는 비공개 승인 명단이나 연락처를 공개 저장소에 올리지 않고 관리해야 합니다.

## 적용의 한계

이 문서와 라이선스는 이용 권한을 정하는 조건입니다. 현재 공개 저장소·릴리즈의 다운로드를 차단하거나, 허락받지 않은 실행을 기술적으로 막는 로그인·라이선스 키 인증 장치가 아닙니다. 기존에 적법하게 부여된 권리, 제3자 라이선스 및 플랫폼 약관상 권리는 그대로 존중됩니다.
