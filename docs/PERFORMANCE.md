# 성능과 지원 범위 — v0.9.3

파일 수·크기·장치·캐시·접근 권한에 따라 시간이 달라집니다. v0.9.3은 Windows 파일 전송의 메타데이터 보존 검사를 수정한 버전이며 새 성능 배수를 측정하거나 보장하지 않습니다.

## 처리 비용과 결과 해석

- 폴더 분석은 실제 디렉터리 항목을 탐색합니다. 제외 조건·숨김 파일·하위 폴더 설정이 검사 범위를 정합니다. 화면 필터는 실제 검사 범위를 바꾸는 설정과 구분합니다.
- 완전 중복은 크기로 후보를 좁힌 뒤 SHA-256과 실제 바이트를 확인합니다. 이름이나 일부 샘플만으로 삭제 가능한 중복을 확정하지 않습니다.
- 유사 후보 탐색에는 지원 형식·특징·후보 수 한도가 있습니다. 일부 유사 쌍을 놓칠 수 있으며 전체 의미 비교나 완전 탐색을 보장하지 않습니다.
- 파일 변경은 현재 근거·충돌·원본 보존을 확인합니다. Windows 스트림 조회가 불완전하거나 ADS·EFS를 보존할 수 없으면 복사·이동을 중단합니다. 검사를 생략해 처리 속도를 높이지 않습니다.
- 파일의 논리적 용량과 실제 디스크 할당량은 다릅니다. delete_files의 보관 데이터도 계속 저장 공간을 사용합니다.

## 복원 정보와 보관 데이터

서명된 작업 기록과 유효한 압축 메타데이터는 원래 경로·해시·상태를 설명합니다. 실제 파일 내용은 별도의 보관 파일 또는 복원 데이터에 있어야 합니다. 메타데이터만으로 사라진 내용을 재생성하지 않습니다.

복원 데이터 최적화는 압축과 같은 청크의 공유를 적용하며, 효과가 없거나 안전하게 완료할 수 없으면 원시 보관본을 유지합니다. ADS·EFS 같은 표현할 수 없는 특성을 조용히 버리지 않습니다. 모든 파일의 용량 감소나 최소 저장량을 보장하지 않습니다.
